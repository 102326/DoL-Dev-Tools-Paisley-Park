# DoL Dev Tools 5.0.0-rc.1 — Paisley Park

这是 5.0 的本地候选包，尚未发布。DoL Dev Tools 帮助 Mod 作者和 Agent 进入真实 Android / WebView，查看现场、调查问题，并沿用项目自己的源码与构建方式验证结果。

本次重点是让已有能力更容易一起使用：

- **找到当前组件的源码**：选定 UI 组件可与明确的源码快照关联；源码已变、缺文件或不支持时如实报告，不猜位置。
- **快速试组件**：接入的 UI 项目可用自己的 Vite Component Lab 编辑真实 Vue 组件并热更新。Lab 属于 UI 工程，不是 Tools 包内的游戏模拟器。
- **连续调查有据可查**：Skill 按需连接现场、源码和制品证据；同版本号也要核对实际字节，避免把旧包当新包。普通调试无需为了记录而新建游戏目标。

保留 4.0.1 的自主 Debug、受支持 Gameplay、预算、执行回执及未知结果保护。没有新 Runtime、后台服务、审批流程或额外生产依赖。

首次使用请看 [快速开始](../README.md#快速开始)，原有 Tools 和 Skill 要保留备份。Source Link 当前仅覆盖选定商店 Toolbar；Component Lab 的内存回调不证明真实购买或存档；完整 Android Mod 自主修复仍未验收。本次平板只读观察与历史实验分开记录，没有重演打赏、改存档或更新 UI 包。

本地候选包括 ZIP、SHA-256 和来源 manifest；manifest 用于核对文件与源码提交，不需要安装进游戏。候选验货结果见 [收口记录](CLOSEOUT_5_0_RC1.md)。
