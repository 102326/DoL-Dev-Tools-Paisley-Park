# DoL Dev Tools 6.0.0 — White Snake

White Snake 让真实 Mod 调查得到的经验，能在下一次开发中继续使用。它基于已发布的 5.1，保留现有 Android/WebView 诊断、Debug、GER 和构建部署入口。

这次新增的内容：

- **按问题找到已有方法。** Skill 从 Mod 知识入口读取适用版本、证据和反例。独立新会话已经自行找到 CE 案例，并实际重建出同摘要的修复包。
- **更具体地调查 Mod 关系。** 显式诊断配方可观察所选 Patch 方法与资源摘要，说明漏采、未决和恢复状态，再交给现有 Evidence。共享修改目标本身不会被当作兼容故障。
- **留下可复现的真实修复。** CE 已装 MapleBirch 仍报缺 Simple 的问题，已定位到可选查询误报。定向配方保留真正错误，在原平板组合中验证了错误消失、加载成员正确及相关设置入口可用。
- **补充框架专业参考。** MapleBirch 的注册、缓存采用、构建字节核对，以及 ModHub 现有检查的使用边界，均可按需查阅。

普通诊断无需这些实验配方，也不要求安装特定 Mod。Patch 观测仍是需审查和显式启用的诊断实验，不提供完整因果图或全生态兼容保证。独立会话构建成功不等于它已独立部署平板；本轮也未验证全部作弊功能。

最低 Node.js 22.12。Gameplay 继续按锁文件安装 XState 5.33.2；存档授权、历史 Unknown、Store 和原有执行合同保持。向新目录解压和安装，保留旧 Tools/Skill，不覆盖旧记录。详见[安装说明](SKILL_INSTALL.md)与[支持及验收范围](CLOSEOUT_6_0.md)。

当前为本地候选，尚未执行 GitHub 发布。Tools 不包含第三方 Mod、游戏、私人证据或辅助写作 Skill。
