# DoL Dev Tools 6.0.0 — White Snake

Paisley Park 是面向 DoL Mod 作者和 Agent 的本地开发工具，用来查看真实 Android / WebView 现场、调查问题，并核对源码、构建包与实际加载结果。可以独立使用，也可以让 Agent 调用。

6.0 重点改善 Mod 调查的接续：遇到类似问题时，Agent 可以找到已有方法，检查版本和适用条件，再继续开发。

## 这次更新了什么

- 增加按问题查阅的 Mod 经验入口，包含 MapleBirch 的注册与缓存、ModHub 已有检查，以及真实兼容案例。经验会保留反例和未知项，换了版本不能直接照搬结论。
- 提供按需启用的 Patch 观测配方，帮助查看所选 Mod 的修改与发布过程。它会记录漏采、未决和恢复状态，接入已有 Evidence；普通诊断不会自动安装探针。
- 留下一条可复现的 CE 修复方法：MapleBirch 已正常加载，作弊拓展却仍报缺 Simple。问题已定位为可选查询误报，原平板组合中相关错误从三条降为零，相关设置入口保持可用。
- 验证经验确实能被下一次任务使用：独立新会话自行找到案例，实际构建并验证了与平板所用包相同的修复版。它没有独立部署设备，这部分不记为通过。

原有 Android/WebView 诊断、Debug、GER 和构建部署入口继续保留。没有迁移旧 Store，也不会清理或重放结果未知的历史操作。

## 如何开始

下载本页附件中的 **DoL-Dev-Tools-6.0.0.zip**，核对 **SHA256SUMS.txt** 后解压。首次使用从 README 的 Doctor、现场采集和 Evidence 开始，需要 Agent 工作流时再安装 Skill。

最低 Node.js 22.12。普通诊断无需安装 npm 依赖；Gameplay 仍需按锁文件安装 XState 5.33.2。升级请保留旧 Tools、Skill 和执行记录，向新目录安装。具体步骤见[安装说明](SKILL_INSTALL.md)。

`artifact-manifest.json` 用于核对包来自哪个源码提交、文件是否一致；`validation.json` 说明实际测过什么。它们是验货材料，不是运行时需要导入的配置。工具包不包含第三方 Mod、游戏或私人现场数据；CE 修复配方也不会自动安装 Mod。

## 已验证与限制

Windows Node 全套回归 **447 通过、1 跳过**；Python **3 通过、1 跳过**。独立包的启动器、Skill 安装、依赖拒绝、临时 SQLite 关闭清理和文件字节核对通过。真实 Android 证据按各自版本保留，没有因文案更新重复计为新实测。

Patch 观测需要审查后显式启用，不提供完整因果图或全生态兼容保证。全部 CE 功能、其它设备和完整无人接管的 Android Mod 修复闭环未验证。详细范围见[支持与验收记录](CLOSEOUT_6_0.md)。
