# DoL Dev Tools 6.0.0 — White Snake

Paisley Park 是面向 DoL Mod 作者和 Agent 的本地开发工具，提供 Android / WebView 现场诊断、源码与制品核验、Mod 兼容性调查，以及可接续的研究经验。可以独立使用，也可以让 Agent 调用。

6.0 将框架机制研究、兼容性调查与定向修复、按需 Patch 观测和跨会话经验接续连到既有流程。遇到相似问题时，Agent 先查已有方法，核对版本、适用条件和反例，再继续开发。

## 这次更新了什么

- **框架机制研究与能力复用**：按问题查阅注册与缓存采用、依赖声明、补丁目标检查和消费者构建方法，优先利用上游已有功能。具体研究对象及版本保留在 [知识入口](MOD_KNOWLEDGE.md)和专业参考中。
- **兼容性调查与定向修复**：结合源码调用、运行证据和实际加载结果，区分可选依赖误报、共享目标与真实故障。已有案例将缺失可选框架导致的假错误从三条降为零，原平板组合的相关设置入口保持可用；不代表全部功能或任意 Mod 组合通过。
- **按需 Patch 观测**：显式选择研究对象，查看修改与发布过程，记录内容指纹、漏采、未决及恢复状态，并接入已有 Evidence。普通诊断不会自动安装探针。
- **跨会话经验接续**：研究经验保留版本条件、反例和未知项。独立新会话已自行找到案例，实际构建并验证与平板所用包相同的修复版；没有独立部署设备，这部分不记为通过。

原有 Android/WebView 诊断、Debug、GER 和构建部署入口继续保留。没有迁移旧 Store，也不会清理或重放结果未知的历史操作。

## 如何开始

下载本页附件中的 **DoL-Dev-Tools-6.0.0.zip**，核对 **SHA256SUMS.txt** 后解压。首次使用从 README 的 Doctor、现场采集和 Evidence 开始，需要 Agent 工作流时再安装 Skill。

最低 Node.js 22.12。普通诊断无需安装 npm 依赖；Gameplay 仍需按锁文件安装 XState 5.33.2。升级请保留旧 Tools、Skill 和执行记录，向新目录安装。具体步骤见[安装说明](SKILL_INSTALL.md)。

`artifact-manifest.json` 用于核对包来自哪个源码提交、文件是否一致；`validation.json` 说明实际测过什么。它们是验货材料，不是运行时需要导入的配置。工具包不包含第三方 Mod、游戏或私人现场数据；案例修复配方也不会自动安装 Mod。

## 已验证与限制

Windows Node 全套回归 **447 通过、1 跳过**；Python **3 通过、1 跳过**。独立包的启动器、Skill 安装、依赖拒绝、临时 SQLite 关闭清理和文件字节核对通过。真实 Android 证据按各自版本保留，没有因文案更新重复计为新实测。

Patch 观测需要审查后显式启用，不提供完整因果图或全生态兼容保证。案例涉及的全部功能、其它设备和完整无人接管的 Android Mod 修复闭环未验证。详细范围见[支持与验收记录](CLOSEOUT_6_0.md)。
