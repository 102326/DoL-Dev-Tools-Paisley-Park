# White Snake 6.0：执行与证据记录

2026-10-15，研发中。基于用户《正式规划 V1.0》及其 5.1 基线校订；本页记录实际执行，不宣称 6.0 已完成。正式 5.1.0、历史 Tusk 资料及 Unknown 不变。

## 基线与完成条件

研发起点为已发布 `v5.1.0` / `main`：`fc52a6ce6c5f15a884f775d9473ae19e133a6987`。独立分支 `development/white-snake-6.0`，不覆盖其它 UI/Mod 工作区。当前任务允许本地开发、受控实验及既有授权测试 App 内的操作；询问已有对话不授权它们替我们改设备。发布、外部账户与未获准目标另按实际授权执行。

正式完成条件保持三条主线和一次联合接续：

- 专业研究：真实框架/Mod 任务完成调查、实际构建、加载身份和代表性行为验证。
- 兼容工程：真实关系/冲突有机制证据，方案在原组合复验并保全相关功能，另有无冲突负对照。
- 经验学习：独立后续会话能发现、限定并使用经验；条件变化和反证修订后，下一次查询能使用新结论。
- 联合接续：至少一次真实任务串联专业知识、执行来源、实际验证与知识回写。

原始观察、来源解释、真实兼容结论分别验收。读源码/编译/静态重叠不算真实业务通过；历史案例不会被重新制造后冒充本轮新成果。

## 首批任务与实验

### A：MapleBirch 角色图层兼容的版本调查

已有真实案例为 LyraMouthCompat051213 0.1.2 对 MapleBirch 5.4.2 的适配；旧精确门禁不等于 API 失效，注册不等于最终模型采用。原工程存在未提交改动，只读引用，必要构建在隔离副本执行。

本轮核对的公开框架为 5.4.3 / `4b4b6e26e934d2e848058f21dfa1df0f71cc455d`，与历史 5.4.2 区分。先调查真实 `Character` 注册、合并与缓存路径，确认一个有实际价值的维护/验证任务，再构建并在获准目标核验；不因同为 5.x 就宣布已兼容。

### B：真实 Patch 实现的受控对照

固定上游输入：TweeReplacer `5094160465b0c5ef034eb5acd3d4f8122bdf8e09`；Linker `bb045cb493b284cef33ddcdebb972ad846349a52`。源码和额外实验依赖只保存在本地忽略目录，不进入 Tools 依赖或发行包。

使用实际上游类与无游戏内容的工作副本/发布替身，比较正常与有观测的执行。先覆盖互不干扰的叠加、前序移除后序锚点、后序覆盖、正则多处匹配、混合客户端顺序、异常和发布未决。结论只覆盖各实际接缝：`okCount`、匹配次数、内容变化、回调完成和发布成功不能混用。任意动态 JS 不做静态推演为成功。

如果方法观测仍不能取得足够的逐规则来源，写明缺口，再研究已有上游扩展点或有界局部插桩。不会把普通 `Integration.collect` 偷偷变成长驻记录器。实验输出保存源码摘要、真实调用顺序、工作副本前后摘要、发布结果及扰动差异；不保存游戏内容。

### C：真实经验的发现、条件变化与修订

已从用户授权的 UI/Mod 兼容对话获得案例，并核对原报告。第一批包括 MapleBirch 嘴部门禁、ReOverfits UI Model Extension；UI 层级/战斗定位材料另作候选，不抢占核心任务。

尤其保留 ReOverfits 从早期仅探查到后续实现并验收的状态演变。原始记录保持原样，当前知识入口指向较新证据。缺少私人原始记录时明确未核验，不因摘要存在而声称证据全部可访问。

独立宿主验证不向提示提供答案或目标文件名，保留实际读取/调用事件；条件改变时不得外推旧设备结论。修订测试使用真实新旧报告的差异，不伪造旧故障。记录模型、宿主、人工提示、实际工具和误用；不报告未经测量的节省率。

## 退出与验收

目标不明确、原生数据/文档身份丢失、资源归属不明时停止该项实验，保留证据；可继续独立源码工作。锁屏认证、未授权账户、目标范围外的持久改动需要用户参与。普通已授权阶段切换不反复审批。

新增局部观测先验证返回值、this、异常、Promise、有限容量及卸载归属；再决定是否进入真实目标。改动仅文档路由时做链接和独立发现检查，不为此重测所有设备。正式收口仍分别报告 Delivered、Validated、Not validated、Known limitations；当前三条正式核心均未整体验收完成。
