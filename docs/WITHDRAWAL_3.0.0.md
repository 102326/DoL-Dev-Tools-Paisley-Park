# Paisley Park v3.0.0 正式发布撤回

> 历史说明：此处记录当时的版本与验证。3.0.0/3.0.1 Release、tag 和原公开提交链已在 2026-10-08 按用户要求移除；当前入口是 README 与 3.0.2。

2026-10-06，按用户重新评估与新目标要求，原正式 `v3.0.0` Release转为草稿，不再作为成熟Gold Experience公开发布；公开稳定latest恢复为 `v2.0.1`。不是删除Release资产、源码回滚或否定既有证明。

保留 `v3.0.0` tag、提交 `9e4aab1372c6a4a0af9e1388ab32decf2199867c`、原ZIP与SHA资产、测试及私有真机Evidence，作为 **Gold Experience Foundation / 3.0开发基线**。源码仍可通过历史tag取得；草稿资产仅在有权限的仓库视图中保留。已被下载的副本不会自动收回，也不宣称远端撤版改变本机代码。

当前Foundation实现的语义观察、reach/equip/purchase-one、pending/原结果记录与原控件守卫继续有效。原[收口](CLOSEOUT_3_0.md)与[发布说明](RELEASE_3.0.0.md)保留为历史，只在当前主线加撤回标记，冻结tag/ZIP字节不改写。

撤回的是“现有范围足以代表正式Gold Experience”的判断。新的必需研发是持续Goal理解、Scene/Working Memory、计划/重规划、事件处理、结果评价、可靠恢复与跨会话能力；新的正式验收包括高层条件购衣/返回穿戴，以及10—20分钟左右的连续Gameplay和无旧聊天上下文恢复。见[架构重新审计与迁移方案](GOLD_EXPERIENCE_REAUDIT.md)。这些是新承诺内Remaining work，不能用Additional coverage标签替代。

本机3.0 Tools与Skill保留作Foundation，不自动回滚至2.0.1。当前指引同步撤版/研发身份，旧指引和文档备份保留；原运行时代码、包元数据与私有证据不修改。包元数据3.0.0只标识该历史基线，不能单独证明正式发布状态。

后续先进行控制/恢复与宿主Decision通路的隔离spike，再按新的范围研发、打磨和必要重构。成熟轮子、创新与重构共同服务目标；不再用“只能薄封装”禁止必要核心，也不重复造底层执行器。正式候选通过后再决定新版本号/tag，不复用或覆盖已冻结的v3.0.0历史，不急着重新发布。
