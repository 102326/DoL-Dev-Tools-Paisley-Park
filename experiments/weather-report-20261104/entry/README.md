# Weather Report entry experiment

These are experimental local Node.js processes. `once.cjs` accepts one raw JSON request on stdin and returns a JSON object with `result` or `error`. `stdio.cjs` calls the same compiled source finder as the one-shot process. The host example is `host.cjs` (the caller may set its timeout; the example defaults to 5 seconds);  it owns the child, correlates replies and closes stdin on shutdown, killing a child that fails to exit after two seconds.

The line protocol accepts UTF-8 JSON with at most 65,536 bytes before newline. Send `{ "type":"find", "requestId":"unique-id", "request": {...} }`; IDs are ASCII letters, digits, underscore or hyphen, 1–64 characters and may be used once per process (maximum 4096 IDs). Replies carry the same ID and either `result` or `error`. A duplicate ID produces an uncorrelated error so it cannot impersonate the original result. Framing and invalid-ID errors are also uncorrelated and should be treated by a host as connection errors. At most two jobs execute and sixteen wait; extra requests receive `BUSY`. Send `{ "type":"cancel", "requestId":"unique-id" }` to abort an outstanding request; its one terminal response is `CANCELLED`, and late completion is discarded. A cancelled running job retains its concurrency slot until the engine settles. Cancel is advisory to the engine; close and host timeout cannot force a non-cooperative function to return without killing the process. EOF or stream failure aborts all jobs and stops output. Output frames are also capped at 65,536 bytes; an oversized result becomes `RESPONSE_TOO_LARGE`. Hosts must consume stdout: if the pending output buffer would exceed 1 MiB, the server closes and aborts outstanding jobs.

`node experiments/weather-report-20261104/entry/host-test.cjs` checks failed-spawn and missing-close cleanup. `node experiments/weather-report-20261104/entry/protocol-test.cjs` exercises protocol and lifecycle with a clearly isolated synthetic stub; it does not validate the engine. Once the TypeScript engine is compiled, `node experiments/weather-report-20261104/entry/benchmark.cjs` runs the real same-engine comparison using the included self-authored fixture. Results describe this machine and workload only. Timing runs do not enable IPC metrics; separate instrumented processes report Node RSS immediately after the one-shot request and after ten reused requests. These are snapshots, not peak memory or whole-system usage. Compare only the recorded engine, entry and fixture hashes. `close()` returns `{closed:true}` after child close, or `{closed:false,reason:"termination-unconfirmed"}` when its kill/stream cleanup fallback expires without proof; callers must not treat the latter as confirmed process termination.
